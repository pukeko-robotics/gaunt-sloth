# v2.0.0-beta.17

- `gth review` can now discover requirements for the reviewed change, matching `gth pr`. Configured under `commands.review.discovery` (off by default), it extracts Jira issue keys deterministically from the branch name or PR description, or runs a discovery agent with configured tools. When invoked with a PR number, discovery evidence is taken from that PR. The prompt is customizable via `.gsloth.review-discovery.md` and inspectable with `gth get review-discovery prompt`.
- `contentSourceConfig.git.mergeBase` allows `gth review` to diff the working tree against the merge base of a target branch (such as `origin/main`). Local uncommitted changes are retained, while commits merged into the target branch after branching no longer appear as phantom deletions.
- Unknown configuration keys in `contentSourceConfig.git` now emit a warning naming the unrecognized keys and `mergeBase` rather than being silently ignored.
- Global npm installs on Node 24 connecting to MCP servers over HTTP/2 (such as Atlassian) no longer fail with an unexpected content type error. `undici` is now loaded lazily only when a TLS dispatcher is configured, and pinned to 8.10.x.
- MCP OAuth requests now explicitly ask for uncompressed responses, fixing authentication failures with providers (such as Atlassian) returning gzipped token payloads. The local OAuth callback server closes cleanly on all exit paths, and browser authorization times out after five minutes rather than hanging.
- The maximum recorded tool result capture size is now configurable via `toolResultCaptureMaxBytes`. Truncation is explicitly recorded so `gth eval` (`tool_result_json_path`) can distinguish a truncated payload from malformed JSON.
- `gth eval` supports a run-level tool coverage floor in configuration (`eval.toolCoverageFloor`), failing the evaluation run if tool coverage falls below the required threshold.
- System prompt notes for working directory, shell commands, and commit conventions are now gated dynamically on active tools rather than tied exclusively to `gth code`.
